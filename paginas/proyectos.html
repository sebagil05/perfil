Mis Proyectos

Portafolio de Trabajos Prácticos

Aquí se presentan los proyectos desarrollados aplicando HTML semántico, diseño modular y fundamentos de CSS con Box Model.

01. Interfaz de Conferencistas y Expertos

Maquetación de tarjetas interactivas de expertos en marketing con marquesina animada, fotos circulares y enlaces directos a perfiles de redes sociales.

  • Tecnologías usadas: HTML5 semántico, CSS3 Flexbox y Flaticon UIcons.
  • Características: Efecto :hover en tarjetas, diseño responsive y botones de acción.

Ver código en GitHub →

02. Rueda Libre - Alquiler de Bicicletas

Sitio web modular compuesto por tres páginas enlazadas (inicio, tarifas de alquiler y reservación de bicicletas en Medellín) con tablas de precios y accesibilidad web.

  • Tecnologías usadas: Tablas accesibles con atributos scope, enlaces relativos y listas de definición <dl>.
  • Características: Navegación bidireccional limpia y validación de peticiones sin errores 404.

03. Hoja de Vida y Perfil Web

Página de presentación profesional que sintetiza la trayectoria formativa, tabla de estudios y formulario de contacto estructurado con etiquetas <label> e <input> vinculados.

  • Tecnologías usadas: Variables CSS (:root), unidades rem y control universal de box-sizing.
